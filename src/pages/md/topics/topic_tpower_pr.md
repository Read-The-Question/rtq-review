$4^2 + 9 = 25$

$

&&  \footnotesize{\maroonC{(+9)}}

1^2,  &&    2^2,  &&  3^2,  &&   4^2, && \ldots, && \ldots, &&\ldots

<div class='question question'>

The **$\underline{same}$** number if missing from all three boxes.

Write the same missing number in each box.

$\Box\:\:\:\:\times\:\:\:\:\Box\:\:\:\:\times\:\:\:\:\Box= \:\:\:512$

</div>
<div class='workings'>
<div class='working'>

Let the missing number $= a$

As per the question,

$
\begin{aligned}
a^3 &=  2 \times 256 \\\\
a^3 &= 4 \times 128 \\\\
a^3 &= 8 \times 64 \\\\
a^3 &= 8 \times 8 \times 8 \\\\
a^3 &= 8^3 \\\\
a &= 8
\end{aligned}
$

The number in the missing box $= 8$

</div>
</div>
<div class='answers'>
<div class='answer'>

$8$

</div>
</div>
