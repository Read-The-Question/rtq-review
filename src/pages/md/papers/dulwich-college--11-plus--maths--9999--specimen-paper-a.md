<div class='question question'>

Each shape in this grid is hiding a particular number so that the three shapes in any row or column add up to the value written 
at the end of that row or column. 

| Diamond |   Sun   |   Sun   | $16$ |
|:-------:|:-------:|:-------:|:----:|
| Diamond | Diamond | Diamond | $12$ |
|  Clove  | Diamond |  Clove  | $18$ |
|   $15$  |   $14$  |   $?$   |  $+$ |
Work out the number that should replace the question mark.

</div>
<div class='workings'>
<div class='working'>

Let the value of diamond, sun and club $= d, s, c$

As per the question,

$
\begin{aligned}
d + s + s           &= 16 \\\\
d + 2s              &= 16 \\\\
d + d + d           &= 12 \\\\
3d                  &= 12 \\\\
c + d + c           &= 18 \\\\
2c + d              &= 18
\end{aligned}
$

Let's find the value of d.

$
\begin{aligned}
3d                  &= 12 \\\\
d                   &= \dfrac {12} {3} \\\\
d                   &= \dfrac {3 \times 4} {3} \\\\
d                   &= \dfrac {\cancel 3 \times 4} {\cancel 3} \\\\
d                   &= 4
\end{aligned}
$

Let's use the value of d to find s.

$
\begin{aligned}
4 + 2s              &= 16 \\\\
2s                  &= 16 - 4 \\\\
s                   &= \dfrac {12} {2} \\\\
s                   &= 6
\end{aligned}
$

Let's use the value of d to find c.

$
\begin{aligned}
2c + 4              &= 18 \\\\
2c                  &= 18 - 4 \\\\
c                   &= \dfrac {14} {2} \\\\
c                   &= 7
\end{aligned}
$

The value of diamond $= 4$

The value of sun $= 6$

The value of club $= 7$

$
\begin{aligned}
\text{Missing value}            &= s + d + c \\\\
                                &= 6 + 4 + 7 \\\\
                                &= 17
\end{aligned}
$

1 \times a                                      &= 3 \times 3 \\\\
a                                               &= 9
\end{aligned}
$

Expected number of blue flowers $= 9$
