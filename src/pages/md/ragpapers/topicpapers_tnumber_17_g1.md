<div class='question subquestion'>

$2 \ \boxed{ \phantom{+} } \  3 =  12  \ \boxed{ \phantom{+} } \   2$

</div>
<div class='workings'>
<div class='working'>

$2 \ \boxed{ \green{ \times } } \ 3 =  12 \ \boxed{ \green{ \div } } \ 2$

Lets verify.

$
\begin{aligned}
\text{Left}       &= 2 \times 3 \\\\
                  &= 6 \\\\
\text{Right}      &= 12 \div 2 \\\\
                  &= \dfrac{12}{2} \\\\
                  &= \dfrac{6 \times 2}{2} \\\\
                  &= \dfrac{6 \times \cancel {2}}{\cancel {2}} \\\\
                  &= 6
\end{aligned}
$

</div>
</div>

<div class='answer'>

$\times, \div$
