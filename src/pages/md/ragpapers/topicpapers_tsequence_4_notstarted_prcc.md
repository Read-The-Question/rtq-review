<div class='question question'>

In this sequence each number is double the previous number. Write in the missing numbers:

</div>
<div class='workings'>
<div class='working'>

As per the question, the sequence would be:

$
\begin{matrix}
&   \footnotesize {\maroonC
{(\times 2)}}
&&  \footnotesize {\maroonC
{(\times 2)}}
&&  \footnotesize {\maroonC
{(\times 2)}}
&&  \footnotesize {\maroonC
{(\times 2)}}
&&  \footnotesize {\maroonC
{(\times 2)}}
&&  \footnotesize {\maroonC
{(\times 2)}}
&&  \footnotesize {\maroonC
{(\times 2)}}  \\
\ldots ,  &&    \ldots , &&     3, &&   6, &&   12, &&      24, &&      48,  &&  \ldots
\end{matrix}
$

$
\begin{aligned}
\text {Second missing number}       &= 3 \div 2 \\\\
                                    &= \dfrac {3} {2} \\\\
\text {First missing number}        &= \dfrac {3} {2} \div 2 \\\\
                                    &= \dfrac {3} {2 \times 2} \\\\
                                    &= \dfrac {3} {4} \\\\
\text {Third missing number}        &= 48 \times 2 \\\\
                                    &= 96
\end{aligned}
$
