<div class='question question'>

Find the missing angles a ̊and b ̊:

![missing image](/papers/missing_image.svg)


%format% - a = 48o, b = 53o
%format% - a = 48o, b = 63o
%format% - a = 58o, b = 53o
%format% - a = 58o, b = 63o

</div>
<div class='workings'>
<div class='working'>

ABBR: $\text{Sum of angles in a triangle} = 180 \degree$


ABBR: $\text{Angles on a straight line add up to} = 180 \degree$.


As per the diagram,

$
\begin{aligned}
a + 132                                                &= 180 \\\\
a                                                      &= 180 - 32 \\\\
a                                                      &= 48 \degree
\end{aligned}
$

Let's use the value of $a$ to find $b$.

$
\begin{aligned}
a + b + 69                                              &= 180 \\\\
48 + b + 69                                             &= 180 \\\\
b + 117                                                 &= 180 \\\\
b                                                       &= 180 - 117 \\\\
b                                                       &= 63 \degree
\end{aligned}
$

</div>
</div>
<div class='answers'>
<div class='option'>
<p>B</p>
</div>
<div class='answer'>

$a = 48 \degree, b = 63 \degree$
