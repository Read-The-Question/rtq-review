<div class='question question'>

Which of these fractions are greater than one half?

- $\dfrac{3}{5}$
- $\dfrac{3}{7}$ 
- $\dfrac{5}{12}$ 
- $\dfrac{8}{15}$ 
- $\dfrac{11}{20}$

</div>
<div class='workings'>
<div class='working'>

A fraction will be bigger than $\dfrac{1}{2}$ if twice of its numerator is bigger than the denominator.

Using trial and error,


| Fraction  |$2 \times$ Numerator|         $> \dfrac{1}{2}$         |
|:-------:  |:------------------:|:-------------------------------: |
| $3, 5$    |  $2 \times 3 = 6$  |             Yes                  |
| $3, 7$    |  $2 \times 3 = 6$  |              No                  |
| $5, 12$   |  $2 \times 5 = 10$  |              No                  |
| $8, 15$   |  $2 \times 8 = 16$  |             Yes                  |
| $11, 20$  |  $2 \times 11 = 22$ |             Yes                  |


$ \dfrac{3}{5}, \dfrac{8}{15}, \dfrac{11}{20} $

</div>
</div>
<div class='answers'>
<div class='answer'>

$ \dfrac{3}{5}, \dfrac{8}{15}, \dfrac{11}{20} $

</div>
