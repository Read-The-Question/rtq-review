ABBR: $\text{Coressponding angles are equal when two parallel lines crossed by a transversal}$.

$b = 28 \degree$

As per the diagram,

$
\begin{aligned}
b + c   &= 50 \\\\

\end{aligned}

</div>
<div class='workings'>
<div class='working'>

Let angle $BAC = a$

As per the question,

As we know that $AB = BC$, using this we get,

Angle $BCA = $ angle $BCA$, 

Angle $BCA = a$

Also, $AD = BD$, using this we get,

Angle $ABD = x$

And $AD = AC$, using this we get,

Angle $ADC = a$

In triangle ACD,

$
\begin {aligned}
a - x + a + a   &= 180 \degree \\\\
3a - x          &= 180 \\\\
{} - x          &= 180 - 3a \\\\
x               &= 3a - 180
\end {aligned}
