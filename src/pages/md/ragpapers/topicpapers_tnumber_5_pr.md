<div class='question question'>

$\dfrac{3}{5} \quad \dfrac{3}{7} \quad  \dfrac{5}{12} \quad \dfrac{8}{15} \quad  \dfrac{11}{20}$

</div>

|:-------:  |:-------------------------------: |
| $3, 5$    |             Yes                  |
| $3, 7$    |              No                  |
| $5, 12$   |              No                  |
| $8, 15$   |             Yes                  |
| $11, 15$  |             Yes                  |
