<div class='question subquestion'>

I will pick out a green one?

</div>
<div class='workings'>
<div class='working'>

$
\begin {aligned} 
\text{Probability}  &= \dfrac { \text{ Favourable Outcomes} } { \text{Total Outcomes} } \\\\
&= \dfrac {3} {2 + 3 + 4} \\\\
&= \dfrac {3} {9} \\\\
&= \dfrac {3} {3 \times 3} \\\\
&= \dfrac {\cancel {3}} {3 \times \cancel {3}} \\\\
&= \dfrac {1} {3}
\end {aligned}
$

</div>
</div>
<div class='answers'>
<div class='answer'>

$\dfrac {1} {3}$

</div>
</div>

<div class='question subquestion'>

I will pick a pencil that isn’t red?

</div>
<div class='workings'>
<div class='working'>

**NOT** selecting a red pencil is same as selecting a blue or green pencil instead.

$
\begin {aligned} 
\text{Probability}  &= \dfrac { \text{ Favourable Outcomes} } { \text{Total Outcomes} } \\\\
&= \dfrac {2 + 3} {2 + 3 + 4} \\\\
&= \dfrac {5} {9}
\end {aligned}
$

</div>
</div>
<div class='answers'>
<div class='answer'>

$\dfrac {5} {9}$

</div>
