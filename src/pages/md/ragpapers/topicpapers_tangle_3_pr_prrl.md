<div class='question question'>

In the diagram below the straight lines $ABG$ and $DEF$ are parallel. Lines $CB$ and $EG$ are also parallel. Find the angles marked $𝑎$, $𝑏$, $𝑐$ in the diagram.

*The diagram is not drawn accurately*.

![tonbridge-school--11-plus--maths--9999--sample-paper-1/section-1-question-13-00.png](/assets/tonbridge-school--11-plus--maths--9999--sample-paper-1/section-1-question-13-00.png "tonbridge-school--11-plus--maths--9999--sample-paper-1/section-1-question-13-00.png")

</div>
<div class='workings'>
<div class='working'>

ABBR: $\text{Interior opposite angles are equal when two parallel lines crossed by a transversal}$.

ABBR: $\text{Coressponding angles are equal when two parallel lines crossed by a transversal}$.

As per the diagram,

$a = 28 \degree$

$b = 28 \degree$

Let's use the value of $b$ to find $c$.

As per the diagram,

$
\begin{aligned}
b + c   &= 50 \\\\
28 + c  &= 50 \\\\
c       &= 50 - 28 \\\\
c       &= 22 \degree
\end{aligned}
$

</div>
</div>
<div class='answers'>
<div class='answer'>

$
\begin{aligned}
a   &= 28 \degree \\\\
b   &= 28 \degree \\\\
c   &= 22 \degree 
\end{aligned}

<div class='question question'>

In the diagram below, triangle $\text{ABC}$ is isosceles with $\text{AB} = \text{BC}$  ; triangle $\text{ABD}$ is isosceles with $\text{AD} = \text{BD}$ ; triangle $\text{ADC}$ is isosceles with $\text{AD} =  \text{AC}$ . 

$x = \text{ABC}$ in degrees. Use algebra to calculate the size of angle $𝑥$. 

![tonbridge-school--scholarship--maths--2016--sample-paper-1/section-1-question-4-00.png](/assets/tonbridge-school--scholarship--maths--2016--sample-paper-1/section-1-question-4-00.png "tonbridge-school--scholarship--maths--2016--sample-paper-1/section-1-question-4-00.png")

</div>
<div class='workings'>
<div class='working'>

Let angle $BAC = a$

As per the question,

As we know that $AB = BC$, using this we get,

Angle $BCA = $ angle $BCA$, 

Angle $BCA = a$

Also, $AD = BD$, using this we get,

Angle $ABD = x$

And $AD = AC$, using this we get,

Angle $ADC = a$

In triangle ACD,

$
\begin {aligned}
a - x + a + a   &= 180 \degree \\\\
3a - x          &= 180 \\\\
{} - x          &= 180 - 3a \\\\
x               &= 3a - 180
\end {aligned}
$

</div>
</div>
<div class='answers'>
<div class='answer'>

$x = 3a - 180$

</div>
</div>
