a                               &= \dfrac {16 \times \cancel 2 \times \cancel {20} \times \cancel 5} {\cancel 2 \times \cancel 5 \times \cancel {20}} \\\\

Dave has a lot of tables.

Each rectangular table seats $8$ people.

Each round table seats $5$ people.

What is the smallest number of tables of each type that 
Dave needs to use to seat $35$ friends and himself, without any empty seats? 

</div>
<div class='workings'>
<div class='working'>

| Number of $8$ seated tables | Number of $5$ seated table | Total seats | Empty seats |
|:---------------------------:|:--------------------------:|:-----------:|:-----------:|
|              4              |             1              |      37     |      1      |
|              3              |             3              |      39     |      3      |
|              2              |             4              |      36     |      0      |
|              1              |             6              |      38     |      2      |
