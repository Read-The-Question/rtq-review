**Question**

Using a scale of $1 \ \text{centimetre }$to represent $1 \ \text{kilometre}$, 
how many centimetres would represent $11 \ \text{kilometres}$?

<div class="working" style="margin: 1rem 0; padding: 0.85rem 1rem; border: 1px solid #9ea7b3; border-radius: 6px;">

**Working**

Let the map distance $= a$

Using equivalent ratio,

$
\begin{aligned}
1 \ \text{cm} : 1 \ \text{km}         &= a \ \text{cm} : 11 \ \text{km} \\\\
\dfrac {1} {1}                        &= \dfrac {a} {11} \\\\
a                                     &= 11 \ \text{cm}
\end{aligned}
$

Map distance $= 11 \ \text{cm}$
</div>
<div class="tips placeholder" style="margin: 1rem 0; padding: 0.85rem 1rem; border: 1px solid #9ea7b3; border-radius: 6px;">

**Working**

Using ratio,

$
\begin{array}{cccccccccccccc}
  & \text{actual}          &:& \text{map} \\\\
= & 1 \ \text{km}       &:& 1 \ \text{cm} \\\\
= & 1 \times 11         &:& 1 \times 11 \\\\
= & 11 \ \text{km}      &:& 11 \ \text{cm}
\end{array}
$

Map distance $= 11 \ \text{cm}$
</div>
